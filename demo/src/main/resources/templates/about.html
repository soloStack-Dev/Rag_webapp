About memInfo

A grounded, retrieval-augmented knowledge assistant built for your PDFs.

What is memInfo?

memInfo is a personal enterprise RAG application that converts uploaded PDF knowledge into searchable vector representations. Users can then ask questions and receive answers grounded in the retrieved document content.

How RAG Works

  1. PDF documents are uploaded
  2. Text is extracted and cleaned
  3. The text is split into overlapping chunks
  4. Each chunk becomes an embedding vector
  5. Vectors are stored in Chroma
  6. A question is embedded and matched by similarity
  7. Gemini generates a grounded answer from the retrieved context

Privacy & Security

  • Credentials and API keys stay server-side and are never sent to the browser.
  • Only PDF uploads are accepted, with a 20 MB size limit.
  • Answers are grounded in your uploaded sources; the assistant will not fabricate facts.
  • Database access uses parameterized JPA operations.
